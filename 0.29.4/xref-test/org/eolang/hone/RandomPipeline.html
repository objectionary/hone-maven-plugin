12  /**
13   * A random Java class with one stream pipeline in it.
14   *
15   * <p>The pipeline is a walk through a typed grammar of the Stream API: a
16   * source, a few intermediate operations, a terminal. Every step is picked from
17   * the productions that the current element domain allows, so whatever comes out
18   * compiles. The walk is seeded, therefore the same seed yields the same class on
19   * every machine and in every run, and a failure found once can be looked at
20   * again.</p>
21   *
22   * <p>{@link Grammar} holds the productions the walk picks from, and says which
23   * element domains and which corners of the terminal API they reach.</p>
24   *
25   * <p>One pipeline per class is deliberate. The JVM verifies a class as a whole,
26   * so a rewrite that corrupts one pipeline takes down every method around it; in
27   * its own class it takes down only itself, and the other pipelines still
28   * report.</p>
29   *
30   * <p>The class prints two lines: the value its pipeline produced and the number
31   * its {@code peek} accumulated. The second line is the traversal contract — a
32   * pipeline may be fused into anything at all, but it must still walk the same
33   * elements, and it must still stop where it stopped. A {@code peek} may
34   * therefore sit in front of anything except {@code count()}, the one terminal
35   * the API allows to skip the traversal altogether.</p>
36   *
37   * <p>The grammar does not step around the operations that the rewrite has been
38   * known to break — every shape behind #787, #788, #790, #794, #798, #799, #804,
39   * #805 and #811 is still reachable, since a generator that avoids the defects we
40   * already know about would only prove that we know about them, and nothing
41   * about a regression. Nothing is quarantined at the moment: {@code
42   * quarantined()} names the shapes that break the rewrite today, so that a suite
43   * failing on them every night does not report what is already filed, and both
44   * of the clauses it held have been deleted along with the issue that owned
45   * them.</p>
46   *
47   * <p>A pipeline is more than the operators in it, so the walk also picks the
48   * frame the pipeline sits in, and each frame opens productions the others
49   * cannot reach. It picks who holds the method: a {@code static} one, or an
50   * instance one, where a lambda may read {@code this} and become an instance
51   * method itself, which is the whole population that {@code 121} and {@code 131}
52   * exist for and that #689 found empty. It picks whether the body catches what
53   * the pipeline throws, and only a body that catches may draw a {@code boom}
54   * operator, which throws from inside the walk and names the element it threw on:
55   * the message is the oracle for how far a fused body got before it unwound. The
56   * four arguments the method takes — a {@code long}, an {@code int}, a
57   * {@code double} and a {@code String} — are captured by lambdas all over the
58   * grammar, so the capturing metafactory shapes that {@code 112}–{@code 126} lift
59   * are reachable from any domain, in any count and any mix of types.</p>
60   *
61   * <p>Two properties of the pipeline as a whole are picked last, once the walk
62   * knows where it ended. A pipeline may go {@code parallel()}, which no rule may
63   * fuse a {@code skip} or a {@code distinct} through — {@code 222}–{@code 225}
64   * revert exactly that — and which is offered only when nothing counts the
65   * traversal and the terminal reduces no floating point, so that what the class
66   * prints stays the same on every run. And a terminal may return nothing at all:
67   * a {@code forEach} that accumulates, whose only oracle is the number the peek
68   * line carries.</p>
69   *
70   * <p>Reaching a shape is not the same as reaching it soon, and widening the
71   * grammar re-deals every seed. #811 — two operators in a primitive-stream run
72   * whose trailing {@code boxed()} keeps it in the boxed domain — was found at seed
73   * 334 of the walk as it stood before this grammar grew, already well outside the
74   * 120 seeds walked by default, and the re-dealt walk does not reach it inside 360
75   * at all. That is the argument for the deterministic pack: a shape the walk finds
76   * earns one of its own under {@code optimize/streams/} the day it is understood,
77   * because the walk is the net that catches a defect, not the test that keeps it
78   * caught.</p>
79   *
80   * @since 0.30.0
81   */
82  final class RandomPipeline {

264     /**
265      * What an intermediate step may be, an operation being three times as
266      * likely as a conversion to another element domain or a peek. A frame adds

268      * {@code this} and a guarded body throws about as often as it peeks.

270     private static final List<String> ROLES = Arrays.asList(
271         "stage", "stage", "stage", "stage", "stage", "stage",
272         "turn", "turn", "peek", "peek"

304     /**
305      * Print the Java source of the class.
306      * @param pkg The package to put the class in
307      * @param name The name of the class, also the label of its printed value
308      * @return Java source code, ready for {@code javac}
309      */
310     String java(final String pkg, final String name) {
311         final List<String> walk = this.rolled(new Grammar());
312         final String[] frame = walk.get(0).split("\\|", 3);
313         final StringBuilder pipe = new StringBuilder(Grammar.code(walk.get(1)));
314         for (final String step : walk.subList(2, walk.size())) {
315             pipe.append(RandomPipeline.EOL).append('.').append(Grammar.code(step));
316         }
317         return String.format(
318             RandomPipeline.TEMPLATE,
319             pkg,
320             name,
321             RandomPipeline.body(
322                 RandomPipeline.shape(
323                     frame[2], walk.get(walk.size() - 1).split("\\|", 3)[1]
324                 ),
325                 pipe.toString()
326             ),
327             RandomPipeline.modifier(frame[1]),
328             RandomPipeline.call(frame[1], name)
329         );
330     }

332     /**
333      * The walk this seed settles on, re-rolled away from every quarantined
334      * shape.
335      * @param grammar The grammar to walk
336      * @return The grammar lines the class is printed from, the frame first
337      */
338     private List<String> rolled(final Grammar grammar) {
339         List<String> found = new ArrayList<>(0);
340         for (int attempt = 0; attempt < RandomPipeline.ATTEMPTS; ++attempt) {
341             final List<String> walk = RandomPipeline.walk(
342                 grammar, new Random(RandomPipeline.scrambled(this.seed * 31L + attempt))
343             );
344             if (RandomPipeline.quarantined(walk).isEmpty()) {
345                 found = walk;
346                 break;
347             }
348         }
349         if (found.isEmpty()) {
350             throw new IllegalStateException(
351                 String.format(
352                     "seed %d walks into a quarantined shape %d times in a row",
353                     this.seed, RandomPipeline.ATTEMPTS
354                 )
355             );
356         }
357         return found;
358     }

360     /**
361      * The seed, mixed.
362      *
363      * <p>{@link Random} scrambles a seed by exclusive-or alone, which moves the
364      * state of two neighbouring seeds by so little that the first few bits they
365      * draw are the same bits — the first {@code nextInt(2)} of seeds 0 to 200
366      * answers the same way almost every time. The walk draws the frame it sits
367      * in first of all, so without a mix of its own three quarters of the seeds
368      * would land in one frame and the axis would be an axis in name only. This
369      * is SplitMix64's finalizer, which spreads one increment across all sixty
370      * four bits.</p>
371      *
372      * @param seed The seed, as the caller counted it
373      * @return A seed whose neighbours are nowhere near it
374      */
375     private static long scrambled(final long seed) {
376         long mixed = seed + 0x9E37_79B9_7F4A_7C15L;
377         mixed = (mixed ^ mixed >>> 30) * 0xBF58_476D_1CE4_E5B9L;
378         mixed = (mixed ^ mixed >>> 27) * 0x94D0_49BB_1331_11EBL;
379         return mixed ^ mixed >>> 31;
380     }

382     /**
383      * One walk through the grammar, as the lines of it that were picked.
384      *
385      * <p>The first line is not a step but the frame the pipeline sits in, as
386      * {@code frame|holder|guard}. The frame is picked before anything else
387      * because it decides which roles the walk may draw from.</p>
388      *
389      * @param grammar The grammar to walk
390      * @param rnd The source of randomness
391      * @return The grammar lines, a frame first, a source second, a terminal last
392      */
393     private static List<String> walk(final Grammar grammar, final Random rnd) {
394         final String holder =
395             RandomPipeline.HOLDERS.get(rnd.nextInt(RandomPipeline.HOLDERS.size()));
396         final String guard =
397             RandomPipeline.GUARDS.get(rnd.nextInt(RandomPipeline.GUARDS.size()));
398         final List<String> roles = new ArrayList<>(RandomPipeline.ROLES);
399         if ("instance".equals(holder)) {
400             roles.add("self");
401         }
402         if ("guarded".equals(guard)) {
403             roles.add("boom");
404         }
405         String domain = Grammar.domain(rnd);
406         final List<String> steps = new ArrayList<>(0);
407         steps.add(String.join("|", "frame", holder, guard));
408         steps.add(
409             String.join("|", domain, "source", grammar.pick(domain, "source", rnd))
410         );
411         final int total = 1 + rnd.nextInt(RandomPipeline.STAGES);
412         boolean observed = false;
413         for (int stage = 0; stage < total; ++stage) {
414             final String role = roles.get(rnd.nextInt(roles.size()));
415             final String fragment = grammar.pick(domain, role, rnd);
416             steps.add(String.join("|", domain, role, fragment));
417             observed = observed || "peek".equals(role) || "boom".equals(role);
418             if ("turn".equals(role)) {
419                 domain = fragment.substring(fragment.lastIndexOf('|') + 1);
420             }
421         }
422         final String end = grammar.terminal(domain, observed, rnd);
423         if (RandomPipeline.raceable(end, observed, domain)
424             && rnd.nextInt(RandomPipeline.RACES) == 0) {
425             steps.add(String.join("|", domain, "race", "parallel()"));
426         }
427         steps.add(end);
428         return steps;
429     }

431     /**
432      * Whether this pipeline may go parallel.
433      *
434      * <p>Two things forbid it. A traversal that is counted, by a {@code peek}
435      * or by a {@code forEach} that accumulates, is counted by several ForkJoin
436      * workers at once into one unsynchronized slot, and what they lose is not
437      * the same on every run. And a terminal that reduces floating point adds in
438      * whatever order the splits happened to combine in. Everything else the
439      * grammar can build is ordered, so a parallel run prints what a sequential
440      * one prints — which is the very contract {@code 222}-{@code 225} keep by
441      * refusing to fuse a {@code skip} or a {@code distinct} into a parallel
442      * pipeline.</p>
443      *
444      * @param end The terminal line the walk picked
445      * @param observed TRUE if something counts the traversal
446      * @param domain The element domain the pipeline ended in
447      * @return TRUE if {@code parallel()} may be appended
448      */
449     private static boolean raceable(final String end, final boolean observed,
450         final String domain) {
451         return !observed
452             && !"void".equals(end.split("\\|", 3)[1])
453             && !RandomPipeline.FLOATS.contains(domain);
454     }

456     /**
457      * The template of the body of the method that holds the pipeline.
458      * @param guard Either {@code plain} or {@code guarded}
459      * @param role The role of the terminal, either {@code end} or {@code void}
460      * @return A template with one {@code %s} where the pipeline goes
461      */
462     private static String shape(final String guard, final String role) {
463         final String body;
464         if ("void".equals(role)) {
465             body = RandomPipeline.WALK;
466         } else {
467             body = RandomPipeline.VALUE;
468         }
469         final String shape;
470         if ("guarded".equals(guard)) {
471             shape = String.format(RandomPipeline.GUARD, RandomPipeline.deeper(body));
472         } else {
473             shape = body;
474         }
475         return shape;
476     }

478     /**
479      * The body of the method, with the pipeline in it.
480      *
481      * <p>The pipeline arrives with one step per line and no indentation at all,
482      * and every line but the first is pushed out to where the {@code %s} of the
483      * shape stands, so that the shapes carry their own layout and nothing has
484      * to be told twice how deep a body is nested.</p>
485      *
486      * @param shape The template of the body
487      * @param pipe The pipeline, one step per line
488      * @return The Java statements of the body
489      */
490     private static String body(final String shape, final String pipe) {
491         final int mark = shape.indexOf("%s");
492         return String.format(
493             shape,
494             pipe.replace(
495                 RandomPipeline.EOL,
496                 RandomPipeline.EOL.concat(
497                     shape.substring(shape.lastIndexOf('\n', mark) + 1, mark)
498                 )
499             )
500         );
501     }

503     /**
504      * The same block, one level deeper.
505      * @param block The Java statements
506      * @return The very same statements, indented by four more spaces
507      */
508     private static String deeper(final String block) {
509         return "    ".concat(
510             block.replace(RandomPipeline.EOL, RandomPipeline.EOL.concat("    "))
511         );
512     }

545     /**
546      * The issue that quarantines this walk, if one does.
547      *
548      * <p>A shape that breaks the rewrite today, emitting a class the verifier
549      * rejects, gets a clause here once it is reported upstream: a walk that
550      * reaches it is re-rolled from a derived seed instead of being generated, so
551      * the suite stays a net for regressions rather than a standing failure. Each
552      * clause is as narrow as the shape it owns and is named by its issue, so
553      * closing the issue widens the walk again by deleting one.</p>
554      *
555      * <p>There is nothing to quarantine right now. The two clauses this method
556      * held are both gone: #804's, a {@code filter} behind a {@code dropWhile},
557      * which lost the copy of the item its predicate eats, and #805's, a
558      * conversion into an object domain with a {@code peek}, a {@code filter} or
559      * another guard between it and a stateful guard, whose keep-frame was read
560      * off whatever opcode happened to sit in front of it. Add the next one the
561      * day the walk finds a shape we cannot fix at once.</p>
562      *
563      * @param walk The lines the walk picked, the frame first
564      * @return The issue that owns the shape, or an empty string
565      */
566     @SuppressWarnings("PMD.UnusedFormalParameter")
567     private static String quarantined(final List<String> walk) {
568         return "";
